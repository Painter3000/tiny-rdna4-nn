# Development history

The full phase-by-phase working documents are intentionally not included in
the curated public source tree. They remain preserved in the qualified
development repository and frozen release artifacts.

The public repository retains:

- qualification summaries under `docs/qualification/`;
- source and archive anchors under `docs/provenance/`;
- validation taxonomy and report templates under `docs/validation/`;
- machine-readable release manifests under `release/manifests/`.

This separation prevents host-specific working paths and internal recovery
instructions from becoming public runtime dependencies.
